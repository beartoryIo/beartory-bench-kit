# Level 1.5 — Skills & Agent Effectiveness

Les cas Level 1.5 doivent être ajoutés avec un identifiant, une suite, un rôle anonymisé, une condition (`baseline`, `skills_on`, `skills_off`, `llm_ab`) et un niveau de sensibilité.

Les cas doivent mesurer une action réellement liée à la compétence : navigateur, document, tableur, design ou revue CI. Un cas purement textuel ne permet pas de conclure sur l'utilité d'une Skill.
